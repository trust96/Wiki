# SideBar

- This component shall be visible only in reserved area pages.
- This component shall be a bottom navigation bar for mobile devices.
  - This component shall be fixed at the bottom of the viewport.
- This component shall be a sidebar for desktop devices.
  - This component shall be fixed on the left side of the viewport.
- There shall be 5 icons evenly spaced across the width of the component:
  - Home icon: When clicked, it shall redirect to the homepage.
  - Search icon: When clicked, it shall redirect to the search page.
  - Add icon: When clicked, it shall open a modal to create a new wiki.
    (this is the main CTA)
  - Notifications icon: When clicked, it shall redirect to the notifications page.
  - Profile icon: When clicked, it shall redirect to the user's profile page.
